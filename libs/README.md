# libs

Общий код, разделяемый девятью сервисами.

| Пакет | Назначение |
|---|---|
| [`platform/`](platform/README.md) | `wb-platform` — ядро: конфиг, логи, трассировка, ошибки, пагинация, outbox, идемпотентность, auth |
| `grpc_stubs/` | Артефакт `buf generate` из `contracts/*.proto`. В `.gitignore`, в репозитории не хранится |

## Правило принадлежности

Код попадает сюда, когда появляется во **втором** сервисе копипастой — не
раньше (иначе это спекулятивная абстракция) и не позже (иначе дублирование
расползается по девяти деплой-юнитам, риск R5 в
[док. 6](../docs/migration/06-risks.md)).

Обратное правило столь же важно: доменная логика конкретного сервиса сюда
**не переезжает**, сколько бы соблазна ни было. `libs/` — инфраструктура,
а не общий домен.
